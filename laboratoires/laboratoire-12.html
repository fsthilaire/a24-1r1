Laboratoire de la semaine 12

Dans ce laboratoire, vous allez faire une installation complète de Windows.

Il sera important de mettre à jour tous les pilotes de la carte-mère.

Ensuite, vous allez utiliser Ubuntu pour faire vos premières manipulations dans Linux.

1. Préparation​

Vous devez installer Windows sur le disque Samsung 250 Go SSD 2.5".

Afin de limiter le nombre de disques visibles lors de l'installation de Windows, désactivez le port SATA 0 dans le BIOS.

Démarrez sur votre clé USB.

Est-ce que ça fonctionne ? Le problème est dans le BIOS.

Indice

Regardez le message en jaune dans le menu de démarrage.

2. Installation de Windows​

Windows doit être installé sur une partition de 70 Go. Effectuez la conversion en Mo correctement en utilisant le facteur 1024.

Le nom d'utilisateur doit être Labo12 et il ne doit pas avoir de mot de passe.

La disposition du clavier doit être Français (Canada).

2.1. Windows Update​

Mettez en pause Windows Update.

Cette action préviendra de faire un long téléchargement des mises à jour pendant le laboratoire.

Faite une courte recherche sur Internet si vous ne savez pas comment faire. Validez la procédure avec l'enseignant.

2.2. Modifier le nom de l'ordinateur​

Vous devez modifier le nom de l'ordinateur pour PC-T@.

Le @ représente votre table de travail qui est inscrite sur la tablette.

Exemple, si vous avez la table 2, l'ordinateur doit se nommer PC-T2

Il est important de respecter les majuscules et minuscules.

Rappel

Le nom de l'ordinateur est le nom qui sera visible sur le réseau. Il représente l'installation de Windows.

Le nom de l'utilisateur est le nom pour se connecter dans Windows.

La procédure se retrouve dans la section Procédures -> Windows -> Renommer un ordinateur.

2.3. Installation des pilotes​

Installez les pilotes de base de l'ordinateur.

Vous devez installer en premier le pilote de la carte réseau de la carte-mère.

Ensuite, utilisez Dell Support Assist pour installer les pilotes restants.

3. Créer des partitions​

Éteignez l'ordinateur.

Activez le port SATA 0.

Démarrez l'ordinateur dans Windows.

Initialisez le disque en MBR.

Créez les partitions ci-dessous sur le disque Seagate 500 Go HDD 3.5".

NomSystème de fichiersTailleLettre

Avertissement

Vous êtes dans Windows, il faut utiliser le facteur 1024.

Créez les dossiers et fichiers ci-dessous.

  • m:\devoir\d1.txt

  • n:\tp.txt

  • o:\systeme\imp.txt

À l'intérieur de chacun des fichiers, inscrivez un texte différent.

4. Ubuntu​

Vous devez faire les actions ci-dessous avec Ubuntu Live.

Fichier ISO

Assurez-vous d'avoir le fichier ISO de Ubuntu sur vos clés USB.

Si vous ne l'avez pas, demandez à un collègue. Nous avons déjà copié les ISO sur les clés USB en classe.

Vous pouvez faire la copie sur les 2 clés simultanément.

Éteignez l'ordinateur.

Assurez-vous de ne pas avoir de disque dans le tiroir SATA .

Désactivez le port SATA 1 pour que Windows ne soit pas accessible.

Démarrez Ubuntu sur votre clé USB et choisissez l'option Essayer Ubuntu.

Rappel

La procédure d'utilisation de Ubuntu Live se retrouve dans la section Procédures -> Ubuntu des notes de cours.

4.1. Partition VOL1​

Montez la partition VOL1 qui se retrouve sur le disque Seagate 500 Go HDD 3.5".

Accédez au dossier de montage.

Effectuez une copie du dossier devoir à la racine de la partition VOL1. Le dossier copié doit avoir comme nom devoirBCK.

Modifiez le contenu du fichier devoir/d1.txt.

Créez le dossier Travaux à la racine de la partition VOL1.

4.2. Partition VOL2​

Montez la partition VOL2 qui se retrouve sur le disque Seagate 500 Go HDD 3.5".

Accédez au dossier de montage.

Renommez le fichier tp.txt pour travaux.txt.

Déplacez le fichier travaux.txt vers le dossier Travaux de la partition VOL1.

Créez le dossier 1r1 à la racine de la partition VOL2.

Créez le fichier texte 1r1/linux.txt. Dans ce fichier, inscrivez LINUX c'est COOL!!!.

4.3. Partition VOL3​

Montez la partition VOL3 qui se retrouve sur le disque Seagate 500 Go HDD 3.5".

Copiez les fichiers ci-dessous dans le dossier systeme de la partition VOL3.

  • /etc/host.conf
  • /etc/fstab
  • /etc/cron.d/anacron

4.4. GParted​

Vous devez créer une nouvelle partition sur le disque Seagate 500 Go HDD 3.5".

Nom (Étiquette)Système de fichiersTaille
LINUX1ext412 Gio
Avertissement

Vous êtes dans Ubuntu. Il faut utiliser le facteur en fonction de l'unité de mesure utilisée.

GParted utilise le facteur 1024.

Montez la partition à l'aide de l'utilitaire Disques.

Créez un dossier examen à la racine de la partition LINUX1.

Créez un fichier texte examen/etudiants dans la partition LINUX1.

Dans le fichier texte, inscrivez vos noms.

Avertissement

Vous devez être administrateur dans l'éditeur de texte et dans nautilus pour faire vos actions.

5. Windows​

Éteignez l'ordinateur et activez le port SATA 1 pour que Windows soit accessible.

Démarrez l'ordinateur dans Windows.

Allez dans la Gestion du disque.

Êtes-vous en mesure d'accéder au contenu de la partition LINUX1 ?

Réponse

Windows n'est pas en mesure d'accéder à la partition. De plus, il n'est même pas en mesure de reconnaitre la partition. Le système de fichiers n'est pas indiqué ainsi que le nom de la partition.

Accédez aux autres partitions et vérifiez que les fichiers et dossiers que vous avez manipulés dans les sections 5.1 à 5.3 sont présents.

6. Installer des périphériques​

Installez les périphériques du laboratoire 11 pour vous pratiquer.

7. Réinitialisation des disques​

Vous devez réinitialiser les disques ci-dessous en GPT.

  • SATA 0 : Seagate 500 Go HDD 3.5"
  • SATA 1 : Samsung 250 Go SSD 2.5"

Effectuez la réinitialisation à partir de Ubuntu Live.

L'utilitaire GParted vous permettra d'effectuer cette action avec Ubuntu.

La procédure se retrouve sur le site Procédures -> Ubuntu -> GParted -> Initialiser un disque.

Redémarrez l'ordinateur. Vous devez avoir la mention No bootable device.
