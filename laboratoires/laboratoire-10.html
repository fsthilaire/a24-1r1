Laboratoire de la semaine 10

1. Configuration du BIOS​

  1. Il faut enlever le mode de démarrage PXE.

    • System Configuration -> Integrated NIC : Enabled

      Cette option permet de configurer la carte réseau interne. Le mode PXE consiste à rechercher un serveur de démarrage pour charger le système d'exploitation à partir du réseau,

  2. Il faut modifier le mode de communication pour les ports SATA.

    • System Configuration -> SATA Operation : AHCI

      Cette option permet de configurer le contrôleur SATA pour déterminer le mode de communication.

  3. Il faut désactiver le Secure Boot.

    • Secure Boot -> Secure Boot Enable : Disabled

      Cette option consiste à vérifier si le périphérique de démarrage est sécurisé dans le cas qu'elle soit activée.

  4. Il faut activer le SATA 0. Le disque Micron est connecté à ce port SATA.

    • System Configuration -> Drives : Cochez SATA 0.

  5. Il faut mettre la bonne date et heure pour l'ordinateur.

    • General -> Date/Time : L'heure est en notation 12 heures AM/PM

Appuyez sur Apply pour enregistrer les modifications.

2. Copie du ISO d'installation​

Insérez le disque Sandisk 256 Go SSD format 2.5" dans le tiroir SATA.

Démarrez l'ordinateur avec Windows PE. Utilisez un port USB 3.

À partir de l'invite de commandes, copiez le fichier Win11_1R1_A24.iso qui se retrouve dans la partition ISO du disque dur Sandisk 256 Go SSD format 2.5" vers la partition Ventoy de votre clé USB.

Pour connaitre la lettre des partitions, il faut utiliser DiskPart. Ensuite, il faut faire la commande list volume pour obtenir l'information.

diskpart
list volume

La liste des partitions ainsi que leur lettre de lecteur s'afficheront. Voici un exemple.

 N° volume   Ltr  Nom          Fs     Type        Taille   Statut     Info
  ----------  ---  -----------  -----  ----------  -------  ---------  --------
  Volume 0     G   Ventoy       NTFS   Partition    16 G   Sain       
  Volume 1     H   ISO          exFAT  Partition    70 G   Sain

Tapez exit une seule fois pour quitter Diskpart.

Dans l'invite de commandes, vous devez copier la commande de copie. L'exemple ci-dessous est en fonction des lettres du tableau ci-dessus.

copy h:\Win11_1R1_A24.iso g:\Win11_1R1_A24.iso /z

Lorsque la copie est terminée, fermez l'ordinateur et retirez le Sandisk 256 Go SSD format 2.5" du tiroir SATA.

remarque

Effectuez la copie pour une seule clé USB. À l'étape 6, vous pourrez faire la copie sur la 2e clé USB.

3. Installation de Windows​

Astuces

Référez-vous à la procédure qui se retrouve dans la section Procédures -> Installation de système d'exploitation -> Windows 11.

Avertissement

Avez-vous retiré le Sandisk 256 Go SSD format 2.5" du tiroir SATA ? Il est important de le retirer pour éviter d'installer Windows 11 sur le mauvais disque.

Vous devez installer Windows 11 sur le disque Micron 256 Go SSD format 2.5". Le disque est déjà dans l'ordinateur dans le port SATA 0.

Démarrez l'ordinateur sur votre clé USB.

Dans Ventoy, vous devez utiliser le fichier Win11_1R1_A24.iso pour faire l'installation.

Important

Le fichier Win11_1R1_A24.iso doit être utilisé uniquement pour le cours. Il a été modifié pour être en mesure d'apprendre les concepts des pilotes.

Pour une installation réelle, veuillez télécharger le ISO officiel sur le site de Microsoft.

3.1. Paramètres d'installation​

Voici les paramètres de l'installation.

Windows doit être installé sur une partition de 100 Go (Windows). Effectuez la conversion en Mo (Windows) correctement en utilisant le facteur 1024.

Vous devez installer l'édition Profesionnel.

Le nom d'utilisateur doit être Etudiant et il ne doit pas avoir de mot de passe.

La disposition du clavier doit être Français (Canada).

4. Installation d'un 2e écran​

Éteignez l'ordinateur.

Installez l'écran LG comme 2e écran. Il doit être l'écran de gauche et il doit être l'écran principal.

Démarrez l'ordinateur.

Est-ce que les 2 écrans fonctionnent ? Pourquoi ?

Réponse

Le 2e écran ne fonctionne pas, car le pilote de la carte graphique est un pilote de base. Ce pilote permet d'avoir un affichage minimal pour être en mesure de faire les premières configurations. Ce pilote n'est pas en mesure de gérer plusieurs écrans. Il faut donc installer le vrai pilote pour la carte graphique.

5. Installation des pilotes de base​

Vous devez utiliser le site Dell Support pour installer les pilotes de bases de l'ordinateur.

Important

Il n'y pas de procédure écrite pour cette section.

Il est important de prendre des notes lors de votre expérimentation.

5.1. Carte réseau​

Allez sur le site de Dell Support à partir de votre portable.

Entrez le Service Tag de l'ordinateur du laboratoire pour accéder à sa page.

Dans la section Pilotes et téléchargements, téléchargez le fichier Pilote de contrôleur Ethernet Intel PCIe.

Copiez le fichier sur votre clé USB et transférez-le dans l'ordinateur du laboratoire.

Exécutez ce fichier sur l'ordinateur du laboratoire pour installer le pilote.

Vérifiez dans le Gestionnaire de périphériques que le pilote de la carte réseau est correctement installé.

Important

Conservez ce pilote dans votre ordinateur, il vous sera utile plusieurs fois et à l'examen de la semaine 15.

5.2. Utilitaire Dell Support Assist​

Allez sur le site de Dell Support à partir de l'ordinateur du laboratoire.

Entrez le Service Tag de l'ordinateur du laboratoire pour accéder à sa page.

Dans la section Pilotes et téléchargements, téléchargez le fichier et exécutez le logiciel.

L'utilitaire va détecter les pilotes manquants et ensuite les installer automatiquement. Cette étape peut prendre plusieurs minutes.

Vérifiez dans le Gestionnaire de périphériques que la liste des périphériques non installées a diminué.

Le 2e écran devrait fonctionner lors que le pilote de l'écran sera mis à jour.

5.3. Chipset​

Les pilotes du Chipset ne sont pas mis à jour à de Dell Support Assist.

Normalement, les pilotes du Chipset aurait été installé par Windows Update. Cependant, cette fonctionnalité a été désactivée dans votre version de Windows.

Allez sur le site de Dell Support à partir de l'ordinateur du laboratoire.

Entrez le Service Tag de l'ordinateur du laboratoire pour accéder à sa page.

Dans la section Pilotes et téléchargements, téléchargez le fichier Logiciel du jeu de puces Intel.

Exécutez ce fichier sur l'ordinateur du laboratoire pour installer le pilote.

Vérifiez dans le Gestionnaire de périphériques que les pilotes du chipset sont correctement installés.

Important

Conservez ce pilote dans votre ordinateur, il vous sera utile plusieurs fois et à l'examen de la semaine 15.

7. Configuration de Windows​

Vous devez faire les configurations de Windows. Ce sont des configurations que vous avez effectuées au début de l'année.

7.1. Disposition des écrans​

Il faut que la disposition des écrans soit faite correctement.

L'écran LG doit être l'écran principal.

7.2. Nom de l'ordinateur​

Le nom de l'ordinateur doit être Gr#Tb@.

Le # représente votre numéro de groupe et le @ représente votre table de travail qui est inscrite sur la tablette.

Exemple, si vous êtes le groupe 5 et vous avez la table 2, l'ordinateur doit se nommer Gr5Tb2

Il est important de respecter les majuscules et minuscules.

7.3. Disposition du clavier​

Il faut avoir la disposition Français (Canada) et Canada multilingue standard.

7.4. Explorateur de fichiers​

Il faut afficher les extensions des fichiers.

Il faut afficher les fichiers masqués.

Il faut mettre Ce PC et non Accès rapide à l'ouverture de l'Explorateur de fichier.

11. Réinitialisation du disque Micron​

Vous devez réinitialiser le disque Micron 256 Go SSD format 2.5" pour effacer son contenu.

Fermez l'ordinateur.

Retirez le disque du tiroir SATA.

Démarrez l'ordinateur sur votre clé USB.

Dans Ventoy, sélectionnez WinPEx64_A2A.iso.

Avertissement

Lorsque Windows PE est complètement chargé, débranchez la clé USB de l'ordinateur.

Ceci vous évitera d'effacer la clé par erreur.

Windows PE fonctionne toujours, car tous les fichiers nécessaires à son fonctionnement sont dans la mémoire vive.

Dans l'invite de commandes, inscrivez les commandes ci-dessous. DiskPart est l'utilitaire en invite de commandes pour faire la gestion des disques.

diskpart

Dans DiskPart, inscrivez les commandes ci-dessous pour effacer complètement le disque.

select disk 0
clean
convert gpt
exit

Redémarrez l'ordinateur.

Vous devriez avoir le message No bootable device si le disque est correctement effacé.

12. BIOS​

Il faut remettre le BIOS en désordre pour le prochain groupe.

  1. Il faut mettre le mode de démarrage PXE.

    • System Configuration -> Integrated NIC : Enabled w/PXE

  2. Il faut modifier le mode de communication pour les ports SATA.

    • System Configuration -> SATA Operation : RAID On

  3. Il faut désactiver le SATA 0.

    • System Configuration -> Drives : Décochez SATA 0

  4. Il faut activer le Secure Boot.

    • Secure Boot -> Secure Boot Enable : Enabled

  5. Il faut mettre une mauvaise date et heure pour l'ordinateur.

    • General -> Date/Time : L'heure est en notation 12 heures AM/PM

Appuyez sur Apply pour enregistrer les modifications.
