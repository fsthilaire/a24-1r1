Laboratoire de la semaine 11

Dans ce laboratoire, vous allez apprendre à installer les pilotes pour des périphériques PCI, PCIe et USB.

1. Vérifier Windows​

Démarrez l'ordinateur pour accéder à Windows. Il a été installé sur le disque Micron 256 Go SSD 2.5" qui est connecté dans le port SATA 0.

Pourquoi Windows ne démarre pas ?

La réponse est dans le BIOS.

Indice

Pensez à ce que vous faisiez pour vérifier si une unité de stockage était bien connectée.

Vous n'avez pas le mot de passe du BIOS également.

Consultez le manuel de l'utilisateur pour avoir la procédure. L'information se retrouve sous la section Désactivation d’un mot de passe système (Page 36) ou Disabling a system password (Page 34).

Indice

C'est une manipulation à effectuer sur la carte-mère.

Voici un article Wikipedia (anglais) qui explique la définition d'un cavalier (jumper). https://en.wikipedia.org/wiki/Jumper_%28computing%29

2. Vérification des partitions​

Pour le disque Micron 256 Go SSD 2.5", veuillez identifier la taille, la lettre du lecteur et le système de fichiers pour les partitions nommées OS, DATA, BCK et 1R1.

Réponse

OS : 71.25 Go NTFS (C:)
DATA : 28.5 Go FAT32 (F:)
BCK : 128 GO exFAT (R:)
1R1 : 9.97 NTFS (N:)

Vous devez installer les pilotes DELL.

  • Carte réseau

  • Chipset

  • Autres (à l'aide du logiciel Dell Support Assist)

4. Installation de périphériques​

Note

Référez-vous aux procédures qui se retrouvent dans la section Procédures -> Windows -> Gestionnaire de périphérique.

Vous devez installer différents périphériques.

Certaines pièces doivent être partagées entre les équipes.

Conservez tous les pilotes fonctionnelles que vous téléchargez sur Internet. Ils vous seront utiles lors des prochains laboratoires et lors de l'examen.

Installez une pièce à la fois.

Clé USB

Pendant cette section, utilisez votre ordinateur portable pour copier le fichier W11_1R1_A24.iso sur la 2e clé USB si ce n'est pas déjà fait.

4.1. Webcam Logitech C270​

Connectez la Webcam dans un port USB.

Vérifiez si la Webcam se retrouve dans le gestionnaire des périphériques.

4.2. Carte réseau sans-fil PCIe - StarTech​

Allez sur le site web de Startech : https://www.startech.com/en-ca

Allez dans la section Support et sélectionnez Find Drivers.

Regardez la pièce pour trouver le numéro de modèle pour faire votre recherche.

Le pilote est dans un programme d'installation.

Exécutez le et lorsque vous serez à cette fenêtre, sélectionnez l'option Installer le pilote ne.

4.3. Carte réseau PCIe - TP-Link​

Regardez la pièce. Il y a le numéro du modèle et la version.

Recherchez le pilote sur la version anglaise du site : https://www.tp-link.com/ca/support/

La version française ne trouve pas la version de la pièce.

Vous devez installer manuellement le pilote à partir du Gestionnaire de périphériques.

Astuce

Pour obtenir faire l'installation, référez-vous au document Procédures -> Windows -> Gestionnaire des périphériques -> Installation du pilote

4.4. Carte réseau PCI - Startech​

Regardez la pièce. Il y a un identifiant avec le site web du fournisseur et un numéro de pièce.

Avertissement

Recherchez le pilote sur les sites web du fournisseur.

Vous devez extraire le fichier zip dans le dossier c:\pilotes\.

N'utilisez pas le programme d'installation Setup.exe.

Trouvez le dossier qui contient le fichier inf pour la version la plus récente de Windows et pour la bonne architecture.

4.5. Carte réseau sans-fil USB​

Cette pièce n'est plus supportée par la compagnie. Le pilote ne peut pas être trouvé sur le site web de la compagnie.

Le pilote se retrouve dans le sous-dossier de c:\pilotes\unsupported\.

Dans ce dossier, il y a des sous-dossiers classés par numéro fournisseur (VID ou VEN). À l'intérieur du dossier fournisseur, il y a des fichiers ZIP qui correspondent au numéro de la pièce (PID ou DEV). Il faut extraire ce zip et faire l'installation manuellement.

Vous devez récupérer l'identifiant du périphérique pour obtenir ces numéros.

Astuce

Pour obtenir l'identifiant, référez-vous au document Procédures -> Windows -> Gestionnaire des périphériques -> Identification d'un périphérique.

4.6. Carte graphique PCIe - NVIDIA​

Regardez la pièce. Il y a le numéro du modèle.

Trouvez le pilote sur le site de NVIDIA.

4.7. Carte HDTV PCI-Express​

Demandez la pièce à un collègue si vous ne l'avez pas.

Avertissement

Recherchez le pilote sur les sites web du fournisseur.

Le pilote sera un fichier exe. Le pilote s'installera en mode assisté, comme pour la carte réseau Dell de la semaine dernière.

Il suffit d'exécuter le programme pour installer le pilote.

Installez le pilote.

5. Réinstallez Windows​

Important

Assurez-vous que le port SATA 0 est désactivé dans le BIOS.

Si le temps vous le permet, installez Windows sur le disque Samsung 250 G0 SSD 2.5". Demandez le disque à l'enseignant.

Installez-le dans le tiroir SATA.

Windows doit être installé sur une partition de 60 Go. Effectuez la conversion en Mo correctement en utilisant le facteur 1024.

Vous devez installer l'édition Famille.

Le nom d'utilisateur doit être Admin1321 et il ne doit pas avoir de mot de passe.

La disposition du clavier doit être Français (Canada).

Vous devez installer les pilotes de la carte réseau, du chipset et utiliser Dell Support Assist.

6. BIOS​

Effectuez ses configurations dans le BIOS.

  1. Il faut enlever désactiver le port SATA 0.
    • System configuration -> Drives : Décochez SATA 0.
  2. Il faut mettre un mot de passe.
    • Security -> Admin Password : Un mot de passe de votre choix.
