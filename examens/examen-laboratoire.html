Examen 1R1 - Laboratoire

La durée de l'examen est de 160 minutes.

L'examen applique la mesure universelle d'apprentissage pour tous (+33% à la durée de l'examen).

L'évaluation vaut pour 20% de la session.

Vous avez accès à votre ordinateur portable, au site du cours, à vos notes personnelles et à Internet.

Aucun logiciel de communication ne doit être en cours d'exécution. Pensez à les fermer correctement à partir de la zone de notification.

Veuillez répondre aux questions sur les feuilles de réponses qui vous ont été données.

L'examen vaut pour 20% de la session.

1. Installation matérielle (1 point)​

Vous devez installer le maximum de mémoire vive en fonction de la mémoire vive que vous avez en votre possession. La mémoire doit être obligatoirement en double-canal.

Vous devez installer la carte réseau sans-fil PCIe dans l’emplacement x16.

Doit utiliser également un pilote dans le zip

2. Configuration du BIOS (1 point)​

Vous devez réinitialiser le mot de passe du BIOS pour être en mesure d’effectuer la configuration qui vous permettra de démarrer sur votre sur votre clé USB.

attention

Il n’est pas possible de prendre l’option « Load Default » du BIOS pour résoudre le problème. Si vous ne trouvez pas la nature du problème ou comment réinitialiser le mot de passe, vous pouvez demander à l’enseignant de passer cette partie, mais aucun point ne sera alloué.

3. Installation et configuration de Windows (3 points)​

Vous devez installer Windows avec le ISO « Win11_1R1_A24.iso ». Il y a 2 disques internes qui sont installés dans l’ordinateur. Un Micron SSD 256 Go Format 2.5’’ et un Sandisk SSD 256 Go Format 2.5’’.

3.1 Utilisation du bon disque (0,5 point)​

Vous devez installer Windows sur le disque interne Micron SSD 256 Go Format 2.5’’ qui est dans le boitier. Utilisez une stratégie vue en classe pour vous assurer d’installer Windows sur le bon disque.

3.2 Installation de Windows (1 points)​

  1. Windows doit être installé sur une partition de 89 Go.
  2. L’édition doit être Professionnel.
  3. Le nom de l’ordinateur doit être PC-EX0@. Le @ représente votre table. Si votre table est le numéro 9, l’ordinateur doit s’appeler PC-EX09.
  4. Le nom de l’utilisateur doit être AdminExa et il ne doit pas avoir de mot de passe.

3.3 Gestion de logiciels (0,5 point)​

Installez uniquement les logiciels ci-dessous. Les programmes d’installation de ces logiciels se retrouvent dans le dossier « C:\logiciels ». Vous devez choisir la bonne architecture pour les logiciels.

  • 7-Zip (32bit)
  • NotePad++ (64bit)

Désinstallez le logiciel ci-dessous:

  • Paint

3.4 Configurations (0,5 point)​

Vous devez effectuer les configurations ci-dessous dans Windows.

  1. Affichez l’extension des fichiers dans l’explorateur de fichiers.
  2. Affichez les fichiers masqués dans l’explorateur de fichiers.
  3. Assignez Bloc-Note comme programme par défaut pour les fichiers « .sql ».

3.5 Windows Update (0,5 point)​

Mettez en pause les mises à jour de Windows. Il est important de ne pas faire les mises à jour pour cet examen. L’enseignant vous donnera le câble réseau lorsqu’il aura validé cette étape.

attention

Les points seront attribués directement lors de la vérification de cette étape.

Si cette action n’a pas été faite correctement, vous n’aurez aucun point. Si vous n’êtes pas en mesure de faire cette action, l’enseignant le fera pour vous, mais aucun point ne sera alloué.

4. Installation des pilotes (8 points)​

4.1 Installation du pilote de la carte réseau interne (1 point)​

Vous devez installer manuellement le pilote de la carte réseau interne.

4.2 Installation du pilote du chipset (1 point)​

Vous devez installer manuellement le pilote du chipset (jeu de puces) de la carte-mère.

4.3 Dell Support Assist (2 point)​

Vous devez installer les pilotes manquant avec l’utilitaire Dell Support Assist.

4.4 Pilote de la carte réseau PCI (2 point)​

Vous devez installer le pilote de la carte réseau PCI.

4.5 Pilote Périphérique USB (2 point)​

Vous devez installer le pilote du périphérique USB mis à votre disposition. Vous devez extraire le contenue fichier ZIP dans le dossier C:\Pilotes\unsupported\. Le pilote est classé par l’identification de la pièce.

6. Ubuntu Live (5 points)​

Demandez à l’enseignant le disque HDD pour faire les actions ci-dessous. Vous devez utiliser Ubuntu Live. Il ne faut pas installer le système d'exploitation.

6.1 Création de partitions. (2 points)​

  1. Réinitialisez le disque en MBR.
  2. Vous devez créer les partitions ci-dessous avec GParted sur le disque Western Digital 500 HDD.

6.2 Gestion des dossiers et des fichiers. (3 points)​

  1. Créez le dossier « identification » à la racine de la partition « NT1 »

  2. Copiez le fichier « etudiant.txt » qui se retrouve sur la partition « IDENTITE » de votre clé USB dans le dossier « identification » de la partition « NT1 ».

  3. Créez le dossier « Pilotes » à la racine de la partition « FT3 ».

  4. Copiez le fichier qui se termine par « .exe » qui se retrouve sur la partition « DRV » de votre clé USB dans le dossier « Pilotes » de la partition « FT3 ».

  5. Copiez le fichier /run/acpid.pid à la racine de la partition « FT3 ».

  6. Créez le dossier « prof » à la racine de la partition « EX2 ».

  7. Créez le fichier texte « francois.txt » dans le dossier « prof » de la partition « EX2 ».

  8. Copiez le fichier /etc/systemd/sleep.conf à la racine de la partition « EX2 ».
